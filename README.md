# Tebak Angka 1-100 (2026-09-18)

Mini game single-file HTML: tebak angka rahasia 1-100 dalam 7x kesempatan.

## Cara jalanin

- Buka `index.html` langsung di browser (double-click), atau
- `python3 -m http.server 8000` lalu buka `http://localhost:8000/daily/2026-09-18-tebak-angka/`

## Aturan

- 7 nyawa, tiap tebakan salah -1 nyawa
- Hint "kekecilan / kebesaran" tiap tebakan
- Skor = sisa nyawa x 10 saat benar
